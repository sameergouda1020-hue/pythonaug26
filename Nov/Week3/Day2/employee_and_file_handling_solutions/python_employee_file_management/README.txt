PYTHON EMPLOYEE MANAGEMENT + FILE HANDLING PRACTICE

1. Employee Management package
   Open a terminal in the employee_project folder.
   Run:
       python index.py

   Employee information is kept in memory while the program is running.

2. File Handling exercises
   Open a terminal in the file_handling folder.
   Run any exercise separately, for example:
       python q01_college_information.py

   Each exercise creates its requested text, CSV, or JSON file in the
   current working directory. Run each exercise from the file_handling
   folder to keep its output files together.

IMPORTANT:
The login exercise stores a password in plain text only because this is
a basic classroom file-handling exercise. Do not use this approach for
real accounts or real passwords.
